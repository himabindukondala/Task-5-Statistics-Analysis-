# Task-5-Statistics-Analysis
# Objective
To perform statistical analysis on the Marketing A/B Testing dataset using Python and evaluate whether there is a significant difference between the advertisement groups.

# Tools Used
- Python
- Pandas
- NumPy
- SciPy
- Matplotlib

# Descriptive Statistics 
- Mean : 24.82 
- Median : 13.00 
- Mode : 1 

# Observation
The mean number of ads viewed is 24.82, while the median is 13. This indicates that the data is right-skewed, with some users viewing a much larger number of ads than most users. The mode of 1 shows that the most common number of ads viewed by users is one.

# T-Test Results
  T-Statistic : 0.214 
  P-Value : 0.831 

# Hypothesis Testing
# Null Hypothesis (H₀)
There is no significant difference between the advertisement groups.
# Alternative Hypothesis (H₁)
There is a significant difference between the advertisement groups.
# Conclusion
Since the **P-value (0.831)** is greater than the significance level of **0.05**, the null hypothesis cannot be rejected.

# Result:
There is no statistically significant difference between the groups based on the total number of ads viewed. The experiment does not provide sufficient evidence to conclude that one group performs differently from the other.
